# 設計判断記録

## 2026-08-29

### 判断
`file_list.py` をルート直下から `src/` 配下へ移し、実行確認用のテストを `test/` 配下に配置する。

### 理由
- プロジェクトの構造を明確化し、ソースコードとテストを分離するため。
- `AGENTS.md` の指示に沿って、作業開始時に必要なフォルダを整備するため。
- 実行時の入口が明確になり、将来の拡張や保守がしやすくなるため。

### 検討した代替案
- ルート直下に置いたまま運用する
- `scripts/` フォルダを追加して管理する

### 影響
- 実行コマンドは `python src/file_list.py` とする必要がある。
- 追加のテストを通して、基本動作の回帰を防ぐことができる。
